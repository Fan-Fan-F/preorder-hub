# Pre-order Hub · 预售中心

电商大促预售玩法的完整演示：定金膨胀、定金期/尾款期分阶段、按序发货。

## 玩法实现

```
定金期（8 分钟演示）→ 尾款期（6 分钟演示）→ 发货阶段
```

- **定金膨胀**：付 ¥50 定金，尾款时抵 ¥150（如「定金 500 抵 1000」）
- **阶段门控**：定金期外不能下定，尾款期内才能补款，超时提示定金退回
- **预售进度**：已预定/库存进度条，营造稀缺感
- **订单状态**：已下定 → 已付全款（待发货），三段步骤条可视化
- **实付合计**：定金 + 膨胀抵扣后的尾款，账算得明明白白
- localStorage 持久化订单

## 运行

浏览器直接打开 `index.html`。演示节奏以分钟计（真实场景按天配置 `phases`）。
